# Portal IFNMG — estudo de interface de login

Projeto pessoal de estudo em **HTML e CSS**, inspirado na identidade visual do IFNMG. Criei esta página para praticar a estrutura de um formulário de login e sua apresentação visual.

> Este é um exercício independente. Não é o portal oficial do IFNMG e não deve ser usado para inserir credenciais reais.

## O que a interface apresenta

- Campo de e-mail/usuário e senha.
- Opção visual “Lembrar minha senha”.
- Botão de entrada.
- Links visuais para cadastro e recuperação de senha.
- Imagens e estilos da página.

## Como visualizar

1. Baixe ou clone este repositório.
2. Abra a pasta `PROJETO IFNMG`.
3. Abra o arquivo `SITE PORTAL IFNMG.html` no navegador.

Não é necessário instalar dependências ou executar um servidor para visualizar esta página estática.

## Processo e aprendizado

Comecei pela estrutura HTML do formulário e organizei seus campos, botão e links. Depois trabalhei os estilos em CSS e os elementos visuais da página. O projeto registra uma etapa inicial da minha prática de desenvolvimento web.

## Limitações atuais

A página apresenta apenas a interface. Não possui back-end, autenticação, criação de contas, recuperação de senha ou armazenamento seguro de credenciais. Os links de cadastro e recuperação usam `#`. A opção de lembrar senha é apenas visual.
